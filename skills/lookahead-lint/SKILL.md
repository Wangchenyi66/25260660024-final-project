# 未来函数检测技能

## 静态检查（代码级）
- 信号计算是否使用 `shift(1)` 或显式 rolling 窗口（窗口右端 ≤ 决策日）；
- 禁止出现 `shift(-k)`、中心化窗口 `center=True`、`iloc[t+1:]` 等未来引用；
- 归一化/标准化是否在滚动窗口内拟合（禁止全样本拟合）。

## 动态检查（数据级，截断复算）
1. 随机选取 K=20 个历史截断日 T；
2. 只用 ≤T 的数据重算信号，与全量信号在 T 日的取值比对；
3. 任何不一致 → 未来数据泄露，输出违规清单。

## 输出
 violations 列表（空即通过），每项含：检查项、截断日、差异摘要。
